Questions people ask

Does it submit my work for me?

No. It produces a deliverable for you to review. It never submits to a school platform. Email is only ever a draft, in your mail app or your Gmail Drafts folder, that you read and send yourself.

Is my assignment sent to the cloud?

Not by default. It runs a model on your own computer through Ollama, so the text stays on your machine. Cloud models (Groq, Gemini, OpenAI, Anthropic) are optional, need your own API key, and ask for your consent before any text leaves your computer.

Do I have to pay for anything?

No. Neither TaskWrite nor Ollama costs anything. The only possible cost is a cloud model, and only if you choose to add your own API key later.

What do I need to run it?

Python 3.12, Ollama with a model installed, and a modern browser. VS Code, Word, Gmail and Google Docs are optional and only used if you connect and approve them. Speed and answer quality depend on your computer and the model you pick.

How good are the answers?

That depends on the model. Small local models run on your own computer but make mistakes. TaskWrite checks that every requirement was addressed and labels what it could not verify, so read everything before you use it.

What can it do on my computer?

Only what you approve for that assignment: the model, a calculator, a Python runner, and the connectors you switch on. Generated code runs in a Docker sandbox with no network when Docker is available; otherwise in a limited process, which is not a hardened sandbox, and the app tells you which one ran.

Which apps can it connect to?

VS Code (saves your code files in a folder you choose), web search (only search words leave your computer), Gmail (saves a draft, never sends) and Google Docs (creates one new document, never shares it). Each is off until you allow it, and anything that leaves your computer shows you exactly what will go first.

Can I change an answer afterwards?

Yes. Each finished problem has a Change this button: say what you want different and only that problem is redone. You can also type instructions while it is working; the next step picks them up.

What if it gets stuck or runs out of steps?

If it needs something only you know, such as your topic or data, it pauses and asks. Every model call and retry counts against a fixed step budget (8 by default). At the cap it stops, saves its progress and shows what is left, and you choose whether to continue.

Which files can I upload?

PDF, DOCX and TXT. Scanned or image-only files need OCR, which isn't supported yet. Text in an uploaded file is treated as data: lines that look like instructions aimed at an AI are flagged and kept away from the model.

Is it okay to use for my coursework?

That depends on your school's rules, and you are responsible for following them. TaskWrite is a drafting and learning aid. Check what your course allows, and understand and review everything before you hand it in.
